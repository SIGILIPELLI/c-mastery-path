# C Mastery Path

A free, structured, module-wise C training program — entry level to master level, with runnable code in every module and a hands-on project at the end of each level.

**Live site:** https://sigilipelli.github.io/c-mastery-path/

## Contents

- **Level 1 · Entry** — language foundations
- **Level 2 · Intermediate** — memory, modules, and build tooling
- **Level 3 · Advanced** — data structures, algorithms, systems programming
- **Level 4 · Master** — production-grade systems & performance

## Local development

```bash
python3 -m venv .venv
.venv/bin/pip install mkdocs-material
.venv/bin/python -m mkdocs serve
```
